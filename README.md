# Piedrazul - Formulario (MVC en JavaScript) 📋

> Sistema de formularios para gestionar pacientes, médicos y citas de la Clínica Piedrazul, organizado con arquitectura MVC en JavaScript.

**🇪🇸 Español:** Aplica el patrón **Modelo-Vista-Controlador** en el frontend: capa de presentación (`capaDePresentación`) con los formularios, una **fachada de servicios** intermedia (`fachadaServices`) y la **capa de acceso a datos** con entidades (Paciente, Médico, Cita) y repositorios. Ejemplo claro de separación de responsabilidades en JS puro.

**🇺🇸 English:** A set of appointment/patient/doctor management forms for Clínica Piedrazul implementing an **MVC** architecture in plain JavaScript: presentation layer with the forms, a service facade (business logic), and a data-access layer with entities (Patient, Doctor, Appointment) and repositories.

## ✨ Funcionalidades / Features

- CRUD de pacientes, médicos y citas
- Capas claras: presentación → fachada de servicios → repositorios/entidades
- JavaScript puro sin frameworks

## 🛠️ Tecnologías / Tech Stack

- JavaScript · HTML/CSS · Arquitectura MVC

## 🚀 Ejecución / Getting Started

Abrir `formulario-piedrazul/capaDePresentación/index.html` en el navegador.
